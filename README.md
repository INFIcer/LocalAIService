# LocalAIService（本地 AI 服务）

> 运行在自己电脑上的本地 AI 服务：语音合成、语音识别、声纹向量、人声分离、翻译、视频画面分析与音视频下载。
> 处理都在本机完成，不上传文件，也不产生额外费用。

---

## 一、用途

把常用的内容处理能力集中到本机，统一管理：

| 能力 | 可以做什么 |
| --- | --- |
| 语音合成 | 输入文字和音色，生成语音；音色可以用自己的录音 |
| 语音识别 | 把音频或视频转成文字，并标出情绪与声音事件 |
| 声纹向量 | 把一段音频转成 192 维向量，交给记忆层判断是谁 |
| 人声分离 | 从歌曲或视频里分出人声与伴奏 |
| 翻译 | 多种语言互译 |
| 视频画面分析 | 从视频里挑出关键画面并说明内容，也可以就图片提问 |
| 音视频下载 | 粘贴链接下载视频或音频，可顺带取得字幕与镜头分段 |

除「音视频下载」需要访问目标网站外，所有能力都在本机离线运行：不上传文件，也没有按次计费。

## 二、安装

**前置条件**

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（64 位） |
| 显卡 | NVIDIA 显卡，建议 8GB 显存以上；显存越大，能同时使用的能力越多 |
| 磁盘 | 建议 30GB 以上（全部模型约 17GB，另需运行环境与结果空间） |
| 外部工具 | 格式转换、视频抽帧需要 ffmpeg，获取方式见安装文档 |
| 网络 | 仅安装依赖、准备模型和使用下载功能时需要，其余场景可离线使用 |

**安装步骤**

1. 取得代码：`git clone https://github.com/INFIcer/LocalAIService.git`，或从仓库页面下载压缩包后解压到任意目录；
2. 按 [安装文档](docs/INSTALL.md) 准备 Python 3.11 以上与显卡推理环境；
3. 启动：双击 `启动管理界面.bat`，浏览器会自动打开管理页面（首次启动需要稍等）；
4. 准备模型：在管理界面「模型」页按能力下载，也可以按安装文档里的命令一次性下载。

之后日常使用直接双击 `启动管理界面.bat` 或 `start_webui.bat` 即可。习惯命令行的话，运行
`powershell -ExecutionPolicy Bypass -File start_ai_service.ps1`。

## 三、使用

管理界面用来查看状态、下载模型和调整设置，共五页：

| 页面 | 用途 |
| --- | --- |
| 概览 | 查看显卡占用、各能力是否就绪、最近任务与日志 |
| 模型 | 查看、下载、切换各能力使用的模型 |
| 设置 | 调整空闲卸载、并发等选项，保存后生效 |
| 任务 | 查看排队与执行中的任务，可取消，双击可看参数、结果与错误 |
| 系统 | 查看版本与磁盘占用、开关开机自启、重启服务、查看日志 |

各项能力由本机的其它软件调用（例如聊天助手、剪辑工具），接入方式见文末的接口文档；也可以在任务页查看运行情况与结果。

第一次使用某项能力时会先加载对应模型，需要等十几秒到几十秒；加载完成后可一直使用，长时间不操作会自动卸载，把显存让给其它能力。

生成的文件都保存在本机，可在任务详情里查看或打开，不会上传到任何地方。

## 四、已知缺陷

- 模型不随代码分发，需要单独下载；缺少某个模型时只有对应能力不可用，不影响其它能力。
- 8GB 显存下多个大模型无法同时驻留：切换能力时会先卸载上一个，来回切换需要反复等待加载；同时使用多个能力仍可能提示显存不足。
- 语音识别对口音、背景音乐、过短音频的准确率会下降；声纹接口只算向量、不判断是谁（身份记忆由调用方维护），不做多人分段，也不能当作身份验证。
- 部分网站需要登录或受地区限制，下载可能失败。
- 生成的文件不会自动清理，需要自己定期删除。
- 服务默认只在本机可用，请不要直接暴露到公网。
